# Интернет-газета (Backend)
REST API для интернет-газеты.

## Стек
* Java
* Фреймворк: Spring Boot
* ORM: JPA (Hibernate)
* СУБД: PostgreSQL
* Аутентификация: JWT
* Тестирование: JUnit 5, Mockito

## Функционал
### Пользователи
* регистрация: имя, фамилия, уникальный email, пароль
* аутентификация: email, пароль; при успехе выдается JWT-токен

### Новости
* статья содержит изображение, заголовок и текст
* главная страница: статьи за последние 24 часа, отсортированные по времени публикации
* архив: статьи старше 24 часов, также отсортированные по времени публикации
* пагинация по 5 статей

### Комментарии
* комментарий содержит текста, имя автора и время публикации
* комментарии видны всем
* оставлять комментарии могут только зарегистрированные пользователи
* отсортированы по времени публикации
* пагинация по 3 комментария

### Лайки
* зарегистрированные пользователи могут ставить и снимать лайки
* повторное нажатие снимает лайк
